1. Introduction & Features

NovaCart is a modern, blazing-fast, and highly secure e-commerce platform built with the latest web technologies. It is designed to be easy to set up, customize, and scale.

🛍️ Full Storefront

Product listing, detail pages, search, cart system, and smooth checkout flow.

🎟️ Coupon & Discount System

Create percentage, fixed amount, and free shipping coupons with expiry dates and usage limits.

💳 Stripe Payments

Secure card payments via Stripe Checkout. Supports test and live modes. Cash on Delivery also included.

⚙️ Admin Dashboard

Manage products, orders, users, coupons, and view revenue analytics — all in one place.

🔐 Authentication System

JWT-based secure authentication with protected routes and role-based access control (Admin / User).

📧 Email Notifications

Automatic order confirmation emails sent to customers upon successful purchase.

🤖 AI Chatbot

Integrated AI assistant powered by Google Gemini to help customers find products.

📦 Stock Management

Atomic stock reservation during checkout prevents overselling. Low-stock alerts in the dashboard.

3. Installation Guide

  1. Unzip the downloaded package. You will find a Source_Code folder.
  2. Open a terminal / command prompt and navigate into the folder: 
    cd Source_Code
  3. Install all dependencies: 
    npm install
  4. Create your environment file by copying the example: 
    cp .env.example .env.local
    On Windows: copy .env.example .env.local

4. Environment Configuration

⚠️ Important: The application will NOT work without properly filling in all required environment variables in your .env.local file.

Open .env.local and fill in all values:

# --- Database (Required) ---
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/novacart

# --- Authentication (Required) ---
JWT_SECRET=your_super_long_random_secret_string_here

# --- Application URL (Required) ---
NEXT_PUBLIC_URL=http://localhost:3000

# --- Stripe Payment (Required for card payments) ---
STRIPE_SECRET_KEY=sk_test_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# --- Email Notifications (Required for order emails) ---
EMAIL_USER=your_gmail@gmail.com
EMAIL_PASS=your_gmail_app_password

# --- AI Chatbot (Optional) ---
GEMINI_API_KEY=your_google_ai_key

How to get your MongoDB URI?

  1. Go to cloud.mongodb.com and create a free cluster.
  2. Click "Connect" → "Drivers" → Copy the connection string.
  3. Replace <password> with your database user password.

5. Running the Application

Development Mode

npm run dev

Open http://localhost:3000 in your browser.

Production Build

npm run build
npm start
✅ Tip: For production hosting, we recommend Vercel (free tier available). Just connect your GitHub repository and set your environment variables in the Vercel dashboard.

6. Admin Panel Setup

ℹ️ Note: The Admin Panel is accessible at /dashboard. Only users with the admin or super_admin role can access it.

To grant admin access to your account:

  1. Register a normal account at /auth/register.
  2. Log in to your MongoDB Atlas dashboard.
  3. Open the users collection.
  4. Find your user document and change the role field to "super_admin".
  5. Log back into the website — you now have full Admin access.

7. Coupon & Discount System

NovaCart includes a complete coupon management system. Navigate to /dashboard/coupons to manage your coupons.

Coupon Types

TypeDescriptionExample
PercentageDeducts a % from the order totalCode SAVE20 → 20% off
Fixed AmountDeducts a fixed amount from the totalCode OFF50 → 50 EGP off
Free ShippingWaives shipping feesCode FREESHIP

Coupon Options

  • Expiry Date: Set when the coupon automatically deactivates.
  • Usage Limit: Limit total redemptions (e.g., first 100 customers only). Leave blank for unlimited.
  • Minimum Order Amount: Only activate the coupon if the cart exceeds a set amount.
  • Active / Inactive Toggle: Enable or disable any coupon instantly from the dashboard.

8. Payment Gateway (Stripe)

  1. Create a free account at stripe.com.
  2. Copy your Publishable Key and Secret Key from the Stripe Dashboard → Developers → API Keys.
  3. Paste them into your .env.local file.
  4. Register your Webhook endpoint in Stripe Dashboard → Developers → Webhooks: 
    https://yourdomain.com/api/webhook/stripe
    Select the event: checkout.session.completed
  5. Copy the Webhook Signing Secret and paste it as STRIPE_WEBHOOK_SECRET.
⚠️ Testing: Use Stripe test card number 4242 4242 4242 4242 with any future expiry date to simulate payments during testing.

9. Email Notifications

NovaCart sends automatic order confirmation emails to customers. To enable this:

  1. Enable 2-Factor Authentication on your Google Account.
  2. Go to Google App Passwords.
  3. Create a new App Password for "Mail".
  4. Copy the generated 16-character password and paste it as EMAIL_PASS in your .env.local.
  5. Set EMAIL_USER to your Gmail address.

10. Production Deployment (Vercel — Recommended)

  1. Push your source code to a GitHub repository (make sure .env.local is in .gitignore — it is by default).
  2. Go to vercel.com and create a new project from your repository.
  3. In the Vercel project settings, go to Environment Variables and add all variables from your .env.local file.
  4. Deploy. Vercel will automatically build and host your application.
  5. Update NEXT_PUBLIC_URL in Vercel to your live domain URL.
  6. Update your Stripe Webhook URL to point to your live domain.
  7. In MongoDB Atlas, go to Network Access and allow connections from 0.0.0.0/0 (all IPs) for Vercel compatibility.
