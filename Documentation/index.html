1. Introduction

Welcome to NovaCart! This is a modern, blazing fast, and highly secure E-Commerce platform built using Next.js 14, React, MongoDB, and TailwindCSS. It comes out of the box with an AI-powered Chatbot assistant, Stripe & Paymob payment integrations, and a powerful Admin Dashboard.

2. System Requirements

Before you begin, make sure you have the following installed on your server or local machine:

  • Node.js: Version 18.17.0 or higher
  • NPM / Yarn: Node Package Manager
  • MongoDB: A MongoDB cluster (MongoDB Atlas is recommended)

3. Installation Guide

Follow these steps to set up the project locally or on your server:

  1. Unzip the downloaded package.
  2. Open a terminal and navigate to the Source_Code directory.
  3. Run the following command to install all necessary dependencies:
npm install

4. Environment Configuration

Important: You must configure your environment variables for the application to connect to the database and payment gateways.

In the root folder, you will find a file named .env.example. Rename this file to .env (or create a new .env file) and fill in your credentials as follows:

# MongoDB Connection String
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/novacart

# JWT Secret for Authentication (Generate any random strong string)
JWT_SECRET=your_super_secret_jwt_string

# Public URL (Change this in production, e.g., https://yourdomain.com)
NEXT_PUBLIC_URL=http://localhost:3000

# Gemini API Key for AI Chatbot
GEMINI_API_KEY=your_gemini_key

# Paymob Credentials
PAYMOB_API_KEY=your_paymob_api_key
PAYMOB_HMAC_SECRET=your_hmac_secret
PAYMOB_INTEGRATION_ID=your_integration_id
PAYMOB_IFRAME_ID=your_iframe_id

5. Running the Application

To run the application in development mode:

npm run dev

To build and run the application in production mode (Recommended for live servers):

npm run build
npm start

6. Admin Panel Setup

By default, the first user registered is a regular user. To grant Admin access:

  1. Register a new account on your website normally via the /auth/register page.
  2. Open your MongoDB Database Dashboard (e.g., MongoDB Atlas).
  3. Go to the users collection.
  4. Find your registered user document and change the role field from "user" to "super_admin".
  5. Log back into your account on the website. You will now have access to the Admin Dashboard at /dashboard.

7. Payment Gateways

Stripe Integration

To use Stripe, ensure you have your Stripe Secret Key and Public Key. Update your codebase or environment variables with the live keys to accept real payments. Register your webhook URL in the Stripe dashboard as https://yourdomain.com/api/webhook/stripe.

Paymob Integration

For Paymob (Egypt/MENA), you have entered the integration details in the .env file. Ensure your callback URLs in the Paymob dashboard are set to https://yourdomain.com/api/paymob/verify.
